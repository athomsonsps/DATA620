## Folder layout

Each week uses only the subfolders it actually needs.

| Folder | Contents |
| --- | --- |
| `assignment/` | Jupyter notebooks and R Markdown / Quarto sources, the submitted work |
| `code/` | Standalone Python and R scripts |
| `data/` | Local datasets and edge lists |
| `output/` | Rendered HTML and PDF reports, network plots and charts |
| `resources/` | Instructions, rubrics, and reference material |

Every week folder currently holds a `.gitkeep` so Git tracks it. Topics and dates come from the Brightspace course content page; assignment titles and due dates will be filled in as they are posted.

## Tooling

Python with `networkx`, `pandas`, `matplotlib`, `nltk`, `gensim` and `scikit-learn`; R with `igraph` and `tidytext` where a week calls for it.
